# Атлас цефеид — ЛР5

React-интерфейс для просмотра спектральных классов и коэффициентов зависимости период–светимость. Две страницы работают только на локальной коллекции mock-объектов. Go API, PostgreSQL, Redis, MinIO и интернет для работы запущенного приложения не нужны.

## Требования и запуск

Node.js 20.19+ (проверено на 20.20.2), npm 10.8.2. В WSL:

```bash
cd ~/RIP/cepheids-frontend
npm ci
npm run dev
```

Открыть http://localhost:3000. Для установки зависимостей нужен доступ к npm. Docker и `go run` запускать не требуется.

```bash
npm run lint
npm test
npm run build
npm run preview
```

Production-файлы находятся в `dist`. Preview по умолчанию доступен на http://localhost:4173. При размещении сборки веб-сервер должен возвращать `index.html` для маршрутов приложения (SPA fallback).

## Стек и границы ЛР5

React + TypeScript, Vite, React Router, React-Bootstrap и Bootstrap CSS. Зависимости зафиксированы в `package-lock.json`. Ветка: `cepheids-react-mocks`.

[README курса](https://github.com/iu5git/Web#лабораторная-5) определяет требования, [методичка](https://github.com/iu5git/Web/blob/main/tutorials/lab5/README.md) используется как пример. Уточнение преподавателя: только две доступные страницы — плитка и лента. В нижнем меню четыре пункта: «Лента», «Добавление», «Плитка», «Войти»; последние возможности добавления и входа отключены. Никаких форм создания или входа, CRUD, пользовательских лайков, API, Redux, Context, useOutletContext, Axios, PWA и Pages в этой работе нет. Отчёт и расчёт аппаратных требований оформляются отдельно.

Стиль перенесён из `templates/cepheids_grid.html`, `templates/cepheids_feed.html` и `resources/styles/style.css` бэкенда (ветка `cepheids-postgres-orm`): фон #262626, карточки #515151, акцент #da704d, текст #f2f2f2, шрифт Segoe UI/Arial. Сохранены портретная пропорция 390:844, плитка в две колонки, видео и информация поверх, нижняя панель. Стили ограничены классами цефеид; Bootstrap JavaScript не подключён.

## Страницы и маршруты

| URL         | Поведение                                     |
| ----------- | --------------------------------------------- |
| `/`         | Перенаправление на `/classes`                 |
| `/classes`  | Плитка и фильтр коэффициентов                 |
| `/feed`     | Первый класс текущего отфильтрованного списка |
| `/feed/:id` | Конкретный класс из полной коллекции моков    |

Это два компонента страниц, а не отдельная страница для каждого ID. Неизвестный маршрут перенаправляется на плитку, неизвестный ID показывает сообщение и ссылку возврата.

### Плитка

Четыре ползунка: минимальный/максимальный наклон a (`min_slope`, `max_slope`) и минимальный/максимальный свободный член b (`min_b`, `max_b`). Диапазон каждого −5…0, шаг 0,01. Начальный диапазон показывает все записи. Кнопка «Найти» применяет введённые границы включительно. При неверном порядке границ выводится ошибка, предыдущий результат сохраняется. При отсутствии совпадений показано сообщение, а не полный исходный список.

Карточка содержит изображение, название класса, a, b и число лайков. Нажатие открывает `/feed/:id`. Кнопок удаления нет. Счётчик лайков доступен только для чтения.

### Лента

Вертикальное видео воспроизводится с autoPlay, muted, loop, playsInline. Показаны название, описание с кнопками «Больше»/«Свернуть» для текста длиннее 20 Unicode-символов (точек кода, как rune в Go); до раскрытия показаны ровно 20 символов и многоточие, число лайков, коэффициенты a и b, кнопка «Следующий спектральный класс». При смене класса описание сворачивается.

«Следующий» перебирает отфильтрованный список циклически. Если открытый по прямому URL класс не входит в него, лента перебирает полную коллекцию моков. При пустом списке `/feed` показывает «Лента пуста» и возврат к плитке. Переключение вкладок не перезагружает страницу. Значения и применённый фильтр сохраняются при переходах; после полного обновления браузера возвращаются начальные значения.

## Моки и медиа

`src/data/cepheidClasses.ts` содержит шесть записей `SpectralClass`. Первые четыре используют локальные файлы F/G/K/M из `public/media`. Пятая имеет пустые URL, шестая — несуществующие локальные URL. Это намеренные сценарии проверки заглушек. Они не обращаются к внешнему S3. Значения коэффициентов и отнесение записей к классам — учебные данные интерфейса, не научная калибровка цефеид.

Тип согласован с именами полей API: `id`, `name`, `description`, `pl_slope`, `pl_intercept`, `image_url`, `video_url`, `likes_count`. Системные поля API, не используемые гостевыми страницами, не дублируются.

`CepheidMedia` подставляет `/media/default.jpg` и `/media/default.mp4` при пустом адресе и при ошибке загрузки. Если недоступна сама заглушка, показывается «Медиа недоступно» без повторного запроса по кругу. При смене источника состояние ошибки сбрасывается через React key. Для шестой записи ожидаются ошибки загрузки исходного файла в Network — после них успешно загружается локальная заглушка.

## Компоненты и props

| Компонент           | Назначение и входные данные                                   |
| ------------------- | ------------------------------------------------------------- |
| `CepheidsApp`       | Общее состояние фильтра, маршруты, общий список               |
| `CepheidGridPage`   | Список, диапазон, ошибка, обработчики изменения и применения  |
| `CepheidFilter`     | `range`, `error`, `onChange`, `onApply`; управляемые ползунки |
| `SpectralClassCard` | `spectralClass`; изображение и поля карточки                  |
| `CepheidFeedPage`   | Отфильтрованные `classes`; разрешение ID из URL               |
| `CepheidFeedCard`   | Текущий `spectralClass`, `nextClass`; описание и видео        |
| `CepheidMedia`      | `source`, `kind`, `name`; загрузка и заглушки                 |
| `CepheidNavigation` | Четыре пункта, активная вкладка по URL                        |

Хуки:

- `useState` в приложении хранит вводимый диапазон, применённый диапазон и ошибку; в ленте — раскрытие описания; в медиа — ошибки загрузки источника и заглушки.
- `useEffect` обновляет `document.title` при смене маршрута. Фильтрация — обычное вычисление, а не эффект.
- `useLocation` читает маршрут для заголовка и выделения меню; `useParams` читает ID класса.

Данные идут сверху вниз через props, события передаются обратно через обработчики. `key` карточек использует стабильный ID.

## Проверка при защите

1. Запустить только фронтенд. Показать плитку и ленту, четыре пункта меню и отсутствие запросов к API/S3.
2. Применить диапазоны коэффициентов и перейти из карточки в ленту. Нажать «Следующий», затем вернуться на плитку: фильтр сохранён.
3. Показать неверный диапазон и пустой результат.
4. Показать записи 5 и 6: изображение и видео по умолчанию при пустом и неверном адресе. Открыть `/feed/999`: сообщение о неизвестном классе.
5. Объяснить типы, коллекцию моков, props фильтра и все используемые хуки.
6. Показать проверки `npm test`, `npm run lint` и `npm run build`.

Автотесты проверяют отрицательные и точные границы, оба неверных диапазона, пустой результат, уникальные ID и циклическое переключение классов.
